#### 🔭 What I'm working on

**[unsung](https://github.com/ingrid-owusu/unsung)** — a GitHub profile card for the open-source
work that *doesn't* show up on your contribution graph: reviews given, and PRs & issues you sent to
projects you **don't own**. A dependency-free GitHub Action that renders an SVG and commits it to
your profile. Here's mine, generated by the tool itself:

![My unsung open-source work](./unsung.svg)

**[exform](https://github.com/ingrid-owusu/exform)** — reshape text by *example*, not regex.
Show it one or two `input => output` pairs; it infers the transform and applies it to every line.

**[mdoctest](https://github.com/ingrid-owusu/mdoctest)** — doctest for Markdown, in any language.
Runs the console/code blocks in your docs and verifies (or `--fix`es) their output.
